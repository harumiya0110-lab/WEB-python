# PyStudio

ブラウザー内でPythonを書いて実行できる、学習向けオンライン開発環境です。

## 主な機能

- Monaco EditorでのPythonコード編集と、Pyodide + Web Workerによるブラウザー内実行
- 標準出力・エラー表示、`input()`、実行停止
- 複数ファイル・フォルダー管理、プロジェクト内import
- IndexedDBによるプロジェクトの自動保存と複数プロジェクト管理
- Python学習用の36種類の標準テンプレート（検索、カテゴリー・難易度の絞り込み、お気に入り）
- マイテンプレートの作成、コード・ファイル構成編集、複製、削除
- プロジェクトとテンプレートのZIP出力・インポート
- 全プロジェクト、マイテンプレート、お気に入りのZIPバックアップ・追加復元
- Matplotlibグラフプレビューとpandasの読み込み
- ライト／ダークテーマ

ZIPはPyStudio形式（`pystudio.json`、formatVersion 1）を使用し、UTF-8テキストファイルを対象とします。ZIPの上限は20MB、ファイル数は100件、展開後の合計サイズは20MB、1ファイルは2MBです。バイナリファイルや未対応のZIP形式はインポートできません。インポートしたPythonコードは自動実行されません。

## 保存と安全性について

- プロジェクト、マイテンプレート、お気に入りなどのデータは、利用中のブラウザーのIndexedDBに保存されます。ブラウザーのデータを消去すると、保存データも消える場合があります。
- 別の端末・ブラウザーとの自動同期、Firebase認証、クラウド同期は未実装です。別環境へ移す場合はバックアップZIPを利用してください。
- Pyodideはブラウザー内で動作しますが、ユーザー作成コードの実行は完全なセキュリティ境界ではありません。信頼できないコードの実行には注意してください。
- Matplotlibやpandasなど一部ライブラリは、Pyodideから初回実行時に読み込まれます。接続状況や利用できるパッケージはPyodideの環境に依存します。

## 開発・確認

```sh
npm ci
npm run dev
npm run lint
npm test
npm run build
```

## Renderへのデプロイ

GitHubリポジトリをRenderのBlueprintとして接続してください。ルートの`render.yaml`を読み込み、`npm ci`と`npm run build`でビルドし、`dist`を公開します。SPAルーティング用にすべてのパスを`index.html`へrewriteします。
